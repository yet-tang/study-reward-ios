# iPhone / iPad 学习与娱乐额度控制

面向家庭的 iOS / iPadOS 应用设计：孩子完成学习任务获得积分，再兑换家长选定娱乐 App 的使用额度；家长设置题目、奖励规则、允许时段和可用应用。

**当前处于技术设计阶段。** 仓库暂不包含可运行的应用，尚未完成 iOS 真机验证。

## 项目目标

- 建立“学习任务 → 获得积分 → 兑换使用额度 → 额度耗尽后恢复屏蔽”的完整流程。
- 首版支持单设备本地使用，题库、学习记录、积分和管控状态保存在设备上。
- 在本地功能验证后，逐步增加家长远程管理、人工批改与学习增强功能。

## 技术方案

阅读 [iOS / iPadOS 技术方案 v1.0](docs/ios-learning-control-design-v1.md)。

计划采用 Swift + SwiftUI，配合 Apple 的 FamilyControls、ManagedSettings、DeviceActivity 及系统扩展。首版目标系统为 **iOS / iPadOS 18 及以上**。

设计文档涵盖平台能力边界、积分账本、兑换状态机、跨进程一致性、异常恢复、远程管理及验收要求。

## 首个里程碑：P0 平台验证

在实现完整题库和奖励功能前，先验证决定产品可行性的系统能力：

- [ ] 建立最小主 App 与监测、屏蔽配置、屏蔽动作三个扩展。
- [ ] 在真实家庭共享关系下完成儿童授权，并选择一个娱乐 App。
- [ ] 验证默认屏蔽，以及一次“5 分钟使用额度、30 分钟有效窗口”的兑换。
- [ ] 分别验证用量耗尽、会话到期后恢复屏蔽的行为。
- [ ] 记录锁屏、强退、设备重启和授权撤销时的状态、回调及可见屏蔽结果。
- [ ] 启动主 App 与相关扩展的 Family Controls 分发权限申请。

**验收目标：** 在目标 iPhone 和 iPad 真机上跑通最小流程，记录系统延迟与失败情形，据此确定后续 MVP 的支持范围和发布门槛。
